# Código de conducta

Este repositorio se rige por el [código de conducta de HuellaIP](https://github.com/huellaip/huellaip/blob/main/CODE_OF_CONDUCT.md), adaptado del Contributor Covenant 3.0.

Para reportar un incidente, escribí a [huellaip@googlegroups.com](mailto:huellaip@googlegroups.com) con el asunto «Conducta». Si el incidente involucra a quien administra esa casilla o a alguien del comité técnico, seguí las instrucciones de la sección [Reportar un incidente](https://github.com/huellaip/huellaip/blob/main/CODE_OF_CONDUCT.md#reportar-un-incidente).
