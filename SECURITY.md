# Política de seguridad

Este repositorio se rige por la [política de seguridad de HuellaIP](https://github.com/huellaip/huellaip/blob/main/SECURITY.md).

En `huellas`, el caso más probable es encontrar **un dato sensible en una huella publicada**: una dirección MAC completa, un número de serie, una cuenta, un dominio con un identificador único del equipo o una IP que no debería estar.

**No abras un issue público.** Escribí a [huellaip@googlegroups.com](mailto:huellaip@googlegroups.com) con el asunto «Seguridad», indicando el archivo y el campo, sin copiar el dato. Lo quitamos del repositorio y del historial lo antes posible.
